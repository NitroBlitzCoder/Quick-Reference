# Quick Reference
> Bring your reference workflow inside Blender — no more tab switching.

Quick Reference is a Blender addon that eliminates the friction of importing 
and managing reference images. Import references in seconds, auto-place them 
facing your viewport, and organize everything without leaving your project.

---

## Features

### Free
- Import a single reference image via hotkey or drag-and-drop
- Auto-place image facing the active viewport
- Auto-organize into a dedicated `References` collection
- Lock transforms to prevent accidental movement
- Simple opacity controls


## Installation

1. Download the `.zip` from [Releases](../../releases)
2. In Blender, go to `Edit > Preferences > Add-ons > Install`
3. Select the downloaded `.zip` and enable the addon

**Requires:** Blender 5.0+

---

## Usage

| Action | Shortcut |
|---|---|
| Import Reference | `Shift + R` |
| Toggle Reference Visibility | `Alt + R` |
| Open Reference Panel | Sidebar → `Reference` tab |
